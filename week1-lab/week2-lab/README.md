# Week 2 Lab: Python Data Types and Operators

This folder contains the solutions for the Week 2 Python lab covering basic data types and operators.

## Files included:

### Part A — Data Types
1. `A1_Task1_Integers.py` - Declaring integers, checking types, and simple math.
2. `A1_Task2_Integer_Operations.py` - Working with floor division, modulus, and exponentiation.
3. `A2_Task1_Strings.py` - String concatenation, cases, and indexing.
4. `A2_Task2_String_Slicing.py` - Extracting substrings using slicing.
5. `A3_Task1_Booleans.py` - Working with `True` / `False` and boolean arithmetic.

### Part B — Operators
6. `B1_Task1_Arithmetic.py` - Demonstrating all seven arithmetic operators.
7. `B2_Task1_Comparison.py` - Comparing user inputs using comparison operators.
8. `B3_Task1_Assignment.py` - Sequential demonstration of compound assignment operators.
9. `B4_Task1_Logical.py` - Using `and` to evaluate multiple conditions.
10. `B5_Task1_Bitwise.py` - Bitwise AND, OR, XOR, NOT, and shift operations.
11. `B6_Task1_Membership.py` - Checking for membership in a list using `in` and `not in`.
12. `B7_Task1_Identity.py` - Demonstrating object identity with `is` and `is not`.

### Challenge
13. `Challenge_Login_Validator.py` - A simple login validator demonstrating comparison and logical operators.
